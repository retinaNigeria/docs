title: "Write and publish blog posts"
description: "Create a draft, format content in Visual or Markdown mode, choose a category and thumbnail, and publish articles with readable URLs on your blog."
keywords: ["articles","Markdown","publishing"]
---

Write your TruHuddle article as a private draft, review its appearance, then publish it when it is ready for readers.

1. Open **Articles → New post**. Enter a title; its URL slug follows the title unless you choose your own address.
2. Use Visual mode to write, or Markdown mode to edit the source. Formatting includes headings, bold, lists, links, tables, images, text color, highlights and fonts.
3. Choose a category. Add a thumbnail and an optional SEO title and description in post settings.
4. Save your draft. Preview the article before publishing. Unpublishing removes it from public lists and the developer API.

Article URLs use the slug, such as `/article/our-latest-update`. Avoid changing published addresses unnecessarily. Categories use name-based slugs; duplicate names receive a suffix. Existing category ID links redirect to the category slug.

Images upload from your browser to storage using a signed URL. The application verifies ownership and size before saving the reference. Replacing a managed logo, favicon, SEO image or thumbnail retains the previous file until the new reference is saved, then cleans up an unreferenced managed image.
