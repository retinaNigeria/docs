description: "Resolve pending domains, missing articles, author profile details, unavailable AI, empty analytics and API authentication issues in your workspace."
keywords: ["troubleshooting","domains","API support"]
---

Check these common causes before contacting TruHuddle support. Verify that the correct workspace is selected when reviewing settings or content.

- **Domain still pending:** compare the TXT/CNAME records with the dialog, complete any extra certificate records, confirm HTTPS, and click Check connection again.
- **The free site redirects:** this is expected once your custom address is active.
- **Article missing:** check the selected workspace, publication status and current slug. Drafts never appear in the developer API.
- **Profile details missing:** save Job title and About me in Profile and enable Show Author in Blog Settings.
- **AI or voice unavailable:** confirm the feature was saved, the workspace plan is active and sufficient credit is available. Temporary usage limits can also pause new requests.
- **Analytics empty:** tracking begins after configuration. Blockers and privacy settings may exclude visits. Refresh the app to load the latest report.
- **Monthly traffic reached:** Startup allows 500,000 public page deliveries per calendar month. Access resumes with the next monthly allowance or an Enterprise upgrade.
- **API authentication fails:** use both headers from the same current credential pair. Keep calls server-side and use the platform API hostname.

For help, [contact TruHuddle](https://truhuddle.com/contact). Include the endpoint, status code and approximate time. Never send your secret key, account password or verification code.
